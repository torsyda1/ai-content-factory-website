# AI Content Factory

AI-powered video editing and content production platform.

## About the project

AI Content Factory is an independent software project currently under development.

## Features

- AI-powered video analysis
- Gaming highlight detection
- Professional video editing
- Motion graphics and automated subtitles
- CS2 match analysis
- Content research and production
